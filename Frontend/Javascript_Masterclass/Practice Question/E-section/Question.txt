SECTION G — EXPLAIN THE CODE
10 Questions

Your answer should explain exactly what is happening and WHY, not merely the final output.

G1
function outer() {
    let message = "Hello";

    return function inner() {
        console.log(message);
    };
}

const fn = outer();
fn();

Explain the closure.

G2
const user = {
    name: "Rahul",

    show() {
        setTimeout(() => {
            console.log(this.name);
        }, 1000);
    }
};

user.show();

Explain why the arrow function matters here.

G3
function Person(name) {
    this.name = name;
}

Person.prototype.greet = function () {
    return "Hi " + this.name;
};

const p = new Person("Rahul");

console.log(p.greet());

Explain where greet is stored and how p finds it.

G4

        this.name = name;

        return "Hi " + this.name;

G5

G6

G7
